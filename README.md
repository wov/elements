# 水火之间 · 竖屏下坠 Demo

Godot 4.7 原型，以 iOS 竖屏触控为目标。默认启动场景：`scenes/mobile/descent.tscn`。

## 试玩

用 Godot 打开 `project.godot`，按 F5。电脑可用 A/D 或方向键移动、Q 切换、R 重来；鼠标也可按住横向拖动，轻点画面切换。

手机操作：横向拖动控制位置；轻点画面或底部大按钮切换水火。拖动不会在松手时误切换。顶部可暂停。

## 本版规则

- 自动下落，有重力、最大下落速度；安全平台提供停留思考时间。
- 水停在木板上，火烧穿；水通过水池，火碰水池失败。
- 火接触斜绳可沿绳快速移动；途中变水即可脱绳。
- 无元素衰竭；切换不消耗资源。失败有原因提示，可一键重来。
- 通过关底计数线后直接进入下一关，最佳过关数保存在本机。
- 连续生成模板片段：基础片段、左右镜像片段、双木板/水池组合片段；随章节变化，不单纯加速。旧片段及时回收。

这是用于验证手感的有限模板无限拼接 Demo，尚未加入完整关卡编辑器、音效、商店或付费系统。

## 验证

`godot --headless --path . --script res://tests/descent_test.gd`

覆盖平台落地、水停木板、火烧木板、形态相克、失败重开、暂停、沿绳移动、变水脱绳、连续生成与回收、轻点与拖动区分。

`tests/descent_preview.gd` 可在有图形环境时生成竖屏试玩截图。

## iOS 状态

项目已使用竖屏分辨率、自适应画布、原生触屏事件与大按钮。当前交付为可在 Godot 运行的项目，尚未完成 iPhone 真机验证或签名安装包；后续需在本机配置 iOS 导出模板、Xcode 和开发者签名，再验证刘海安全区、触摸手感、性能和震动。

旧横版场景仍保存在 `scenes/main.tscn`、`scenes/cliff.tscn`；历史说明归档到 `docs/legacy-notes.md`。
