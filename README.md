# Elements（元素）

2D 平台解谜游戏：主角是一团可以切换 **火 / 水** 形态的元素，在不断衰竭中寻找补给、走到终点。

## 核心规则

- **没有跳跃**，只能左右移动
- **元素量**（0~1）**只在移动时衰竭，停留不消耗**——停下来思考是安全的；归零即消散，关卡重来
- **火吃煤块**补充元素量（煤块碎成小块飞进火里的「吃煤」动画）
- **水吸水滴**补充元素量（靠近时水滴会被吸附飞来，融合成一体）
- **相克**：火碰到水滴会被**熄灭**（直接死亡）；水碰到煤块会被**吸走水量**（煤块不消失，有吸收间隔）
- 元素量越低，**体形越小、移动越慢**，体内直接显示 **百分比数字**（紧迫感）
- 目标：走到关卡右端的终点门

> 衰竭/补给数值都可以在 `player.gd` / `pickup.gd` 的导出变量（Inspector）里直接调。

## 运行

需要 [Godot 4.x](https://godotengine.org)（开发环境为 4.7）。

- 用 Godot 打开本目录下的 `project.godot`，按 F5 运行；
- 或命令行：`godot --path .`

## 操作

| 按键 | 功能 |
| --- | --- |
| A / D 或 ← / → | 左右移动（没有跳跃） |
| Q | 切换 火 ↔ 水 形态 |
| R | 重开本关 |

## 项目结构

- `scenes/main.tscn` — 测试关卡（长廊 + 交替补给点 + 终点门）与 HUD
- `scenes/player.tscn` — 玩家（CharacterBody2D + 相机）
- `scenes/pickup.tscn` — 补给（`kind`: COAL 煤块 / WATER 水滴）
- `scenes/exit_gate.tscn` — 终点门
- `scripts/character_frames.gd` — 程序生成主角动画帧（SpriteFrames，四个动画）
- `scripts/player.gd` — 移动、衰竭（移动才耗）、形态切换、百分比、水渍、熄灭、消散
- `scripts/pickup.gd` — 补给与相克交互（吃煤 / 吸附 / 煤吸水 / 熄火）
- `scripts/exit_gate.gd`、`scripts/main.gd` — 通关与 HUD/重开逻辑

## 主角表现

主角使用 `AnimatedSprite2D` 动画帧，当前由 `character_frames.gd` 程序生成占位帧：

- **火**：微微浮空并缓慢起伏；移动时火苗向行进反方向拖曳（迎风变形）
- **水**：贴地的圆形张力水滴（表面轻微抖动）；移动时横向拉伸，并在地面留下逐渐淡出的 **水渍**
- 体内实时显示元素量 **百分比**
- **交互动画**（多边形 + 补间，无粒子效果）：吃煤（碎块飞入 + 火苗一鼓）、水滴吸附融合（涟漪）、煤块吸水（水珠被拽进煤里）、火焰熄灭（蒸汽升腾）

> 正式美术就绪后，给 `AnimatedSprite2D` 换一份编辑器制作的 `SpriteFrames`（动画名不变：`fire_idle / fire_move / water_idle / water_move`）即可，无需改代码。其余占位美术（场景、补给）由多边形 + 补间动画生成。
> 中文 HUD 依赖系统的字体回退；如果显示为方块，需要给项目添加一个包含 CJK 字形的字体。

## 当前设定（可讨论）

- 切换形态**不消耗**元素量，两种形态**共享**同一个元素量槽
- 煤块吸水后**不会消失也不会饱和**（可讨论：吸饱后变成「湿煤」，不再吸水甚至可被火点燃）
- 水滴对火形态**不主动靠近**，只有撞上才会熄灭；对水形态 90px 内开始吸附
