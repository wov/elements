# Elements（元素）

2D 平台解谜游戏：主角可在 **火 / 水** 两种基础形态之间切换，后续用形态与关卡元素互动来解谜。

当前为基础版本：跑、跳、切换形态。

## 运行

需要 [Godot 4.x](https://godotengine.org)（开发环境为 4.7）。

- 用 Godot 打开本目录下的 `project.godot`，按 F5 运行；
- 或命令行：`godot --path .`

## 操作

| 按键 | 功能 |
| --- | --- |
| A / D 或 ← / → | 左右移动 |
| 空格 / W / ↑ | 跳跃 |
| Q | 切换 火 ↔ 水 形态 |
| R | 回到出生点 |

## 项目结构

- `scenes/main.tscn` — 测试关卡（地面、平台、墙壁）+ HUD
- `scenes/player.tscn` — 玩家（CharacterBody2D + 相机）
- `scripts/player.gd` — 移动 / 跳跃 / 形态切换（外观、粒子、`form_changed` 信号）
- `scripts/main.gd` — HUD 与重置逻辑

> 占位美术全部由代码生成（多边形 + CPU 粒子），之后可直接替换为 Sprite2D 动画。
> 中文 HUD 依赖系统的字体回退；如果显示为方块，需要给项目添加一个包含 CJK 字形的字体。
