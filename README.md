# 水火逃生 · 竖屏试玩关

当前默认入口：`scenes/mobile/escape.tscn`。先按 F8 停止旧游戏，再按 **F5 运行项目**；F6 会运行编辑器当前打开的场景，可能还是旧版。

## 本轮试玩目标

一关有终点的逃生挑战：起点可以无限观察，滑出后坍塌开始追赶。水钻管穿过岩层，火接引线高速冲刺。三处分支可选蓝色水管捷径或金色碎片绕行路线，最终冲出洞口。

- 横向拖动移动，轻点画面或底部大按钮切水火。电脑可用 A/D、Q；R 重来。
- 开场先向左进入蓝色管口。水能进管，火会停在管口；管内运输期间锁定为水，出口自动恢复控制。
- 出管后切火接金色引线，前进中的绳子会烧掉。变水可提前脱绳。
- 木板变火烧穿，水池前变水。普通平台只能短暂喘息，坍塌不会因此停下。
- 蓝色管道是更快、更稳的捷径；对侧绕行洞口有更多金色碎片。结算展示耗时、收集数、钻管与接绳次数。
- 起点教学无倒计时；离开后坍塌会追赶，落后时有提示和顶部余裕条，暂停会同时冻结角色和追赶。
- 短音效反馈覆盖切换、钻管、冲刺、收集、成功和失败。

熟练脚本实跑：安全路线约 27 秒、4 次钻管；冒险路线约 29 秒、1 次钻管、15 个碎片。两路都可接 6 次引线。首次操作和观察会更久。

# 水火之间 · 竖屏下坠 Demo

Godot 4.7 原型，以 iOS 竖屏触控为目标。默认启动场景：`scenes/mobile/descent.tscn`。

## 试玩

用 Godot 打开 `project.godot`，按 F5。电脑可用 A/D 或方向键移动、Q 切换、R 重来；鼠标也可按住横向拖动，轻点画面切换。

手机操作：横向拖动控制位置；轻点画面或底部大按钮切换水火。拖动不会在松手时误切换。顶部可暂停。

## 本版规则

- 自动下落，有重力、最大下落速度；安全平台提供停留思考时间。
- 水停在木板上，火烧穿；水通过水池，火碰水池失败。
- 火接触斜绳可沿绳快速移动；途中变水即可脱绳。
- 无元素衰竭；切换不消耗资源。失败有原因提示，可一键重来。
- 通过关底计数线后直接进入下一关，最佳过关数保存在本机。
- 连续生成模板片段：基础片段、左右镜像片段、双木板/水池组合片段；随章节变化，不单纯加速。旧片段及时回收。

这是用于验证手感的有限模板无限拼接 Demo，尚未加入完整关卡编辑器、音效、商店或付费系统。

## 验证
